Finds files in the current workspace by name or path. Every word you type has to appear somewhere in the path, so `paseo usage` finds `memory/facts/paseo-usage.md` and nothing else; there is no fuzzy matching, and Korean works. Words that hit the file name rank above words that only hit a folder. Matching folders are listed first with a trailing slash; picking one narrows the search to it, or in chat mode inserts it as a reference.

A "파일 검색" pill sits above every chat box; its popover searches and puts the pick into the chat box as a quoted path, the same text Paseo's `@` mention inserts. The same search is also an Explorer sidebar tab ("파일 검색") and a Cmd+K item. Enter opens the first result; clicking a row opens that file in Paseo's own file tab. On the phone apps, where the file tab cannot be driven, the path is copied instead.

The same search sits in the composer's attach menu as "파일 검색", a stand-in for `@`, which plugins cannot extend. It searches every open workspace on the host; a picked file or folder becomes a chip, and the agent receives the quoted absolute path, the same kind of reference the `@` mention sends. Matching folders are listed first, with a trailing slash.

On desktop and web, a shortcut (`Cmd+Shift+O` by default, changeable or switchable off under Options; a single character there becomes a typed trigger instead) opens the pill's popover from anywhere in a workspace (the Explorer tab when no chat is open); the file you pick goes into the chat box at the caret. The phone apps have no chat box hook, so use the attach menu there.

The file list honours .gitignore and skips hidden entries. It comes from ripgrep when it is installed on the daemon machine, else from git, else from a plain directory walk, and is refreshed every ten seconds. Requires Paseo 0.13 or later.
