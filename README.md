# paseo-file-search

Paseo 워크스페이스의 파일을 이름·경로로 찾는 플러그인. 기본 파일 검색(Cmd+P)의 퍼지 매칭 잡음과 다중 단어 미지원을 대신한다.

- 띄어쓴 단어를 **모두 포함**하는 경로만 결과에 나온다(퍼지 없음, 한글 OK). 일치하는 폴더는 `이름/`으로 앞에 최대 8개. 패널에서 폴더 클릭은 그 폴더로 검색을 좁히고, 채팅 모드에선 파일처럼 참조로 들어간다.
- 순위: 파일 이름 접두 > 파일 이름 포함 > 폴더 이름 포함, 그다음 얕고 짧은 경로.
- 진입: 채팅 입력창 위 **"파일 검색" 알약**(팝오버, 고르면 입력창에 참조 삽입 후 닫힘), 워크스페이스 상단 **🔍 헤더 버튼**(새 세션처럼 아직 에이전트가 없어 알약이 못 뜨는 때를 위한 같은 팝오버), 탐색기(오른쪽 사이드바) "파일 검색" 탭, Cmd+K → "파일 검색". Enter = 첫 결과.
- 열기: 워크스페이스 라우트의 `?open=file:` 인텐트로 Paseo 내장 파일 탭을 연다(데스크톱·웹). 폰 앱에서는 경로를 복사한다.
- 채팅 참조: 입력창 `+` → "파일 검색"(첨부 소스). `@` 자동완성은 플러그인이 확장할 수 없어서 그 대용이다. 호스트의 열린 워크스페이스 전체를 검색하고, 고른 파일은 칩으로 붙어 에이전트에게 `참조 파일: "/절대/경로"`로 전달된다. 폴더도 검색돼 앞쪽에 나오며(`폴더명/`), 고르면 `참조 폴더: "/절대/경로"`로 전달된다.
- 채팅창 단축키(기본 `Cmd+Shift+O`, Settings → Plugins → 파일 검색 → Options에서 변경·끄기): 워크스페이스에서 누르면 열린 채팅의 알약 팝오버가 열리고(알약이 없으면 탐색기 패널), Enter나 행 클릭으로 고른 파일이 입력창의 커서 위치에 `"상대/경로"`로 들어간다(네이티브 `@`와 같은 형식). `Mod`는 Mac에서 Cmd, 그 외 Ctrl. 설정에 한 글자만 적으면 그 글자를 입력창 단어 첫머리에 칠 때 열리는 문자 트리거가 된다. 행의 "채팅" 버튼은 언제든 같은 동작. 플러그인 SDK에 입력창 훅이 없어 DOM 키 이벤트와 `data-testid="message-input-root"`에 기대므로 데스크톱·웹 전용이고 Paseo 업데이트로 깨질 수 있다.
- 파일 목록: `rg --files`(없으면 `git ls-files`, 그다음 디렉터리 순회), 10초 캐시. `.gitignore`·숨김 항목 제외.

## 개발

```bash
npm install
npm run typecheck
npm test
paseo plugin add ~/paseo-file-search   # 디렉터리 설치
paseo plugin reload file-search        # 수정 반영
```

환경변수 `FILE_SEARCH_RG`로 ripgrep 경로를 지정할 수 있다.
